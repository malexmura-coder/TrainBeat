TrainBeat - to do for the next release

1. Staff notation: what is left after the first version
   - Known limits of the first version (see the header of Notation.kt): rhythm is
     put on a grid of sixteenth notes, so triplets and thirty-second notes come out
     wrong; no beams (flags only); one line of music per staff, so a held note under
     a moving one is cut short; the drum channel is not drawn.
   - Paged scrolling (StaffPaging.kt): the page stays put, the cursor walks through
     the visible bars and the page turns as the last visible bar (at least half on
     screen) is entered. Known limit: the time signature in the header is that of
     the first bar of the page, stale if the metre changes in mid-page.
   - Not seen on a device yet: the page turn, spacing at different widths and on a tablet (the size
     follows the screen until set by hand, 70%-250%, see StaffScale.kt - the
     automatic default is only a guess until tried on a tablet), the grand staff
     height, and how a hand-played (unquantised) file reads.
   - Possible next steps, none decided: triplets, beams, an option for the staff
     spacing, drawing the drums on a percussion staff.
   - Guitar Pro 3/4/5 (.gp3, .gp4, .gp5): GuitarPro.kt, same Score + TabScore as the
     MusicXML reader, same repeat policy (repeats and voltas unrolled by RepeatPlan,
     a repeated section listed twice in the bars; GP3/4 store the number of repeats, GP5
     the number of passes; endings after the first are as long as the first, or until
     the next ending / repeat sign). Written
     from the published description of the format and checked note for note against
     files made by Guitar Pro (not kept in the repo). Not read: dead notes, grace notes,
     bends, slides, hammer-ons, harmonics, trills, strums. No intent filter in the
     manifest (there is no MIME type for it): open from the app's own lists.
   - MusicXML (.musicxml, .xml, .mxl): read into the same Score as a MIDI file (see
     the header of MusicXml.kt), repeats and voltas unrolled (RepeatPlan), a part that
     carries string and fret shown as a TABLATURE (Tab.kt, TabView.kt) and any other
     part as a staff. Known limits: no grace notes, cue notes, ornaments, bends,
     slides or techniques; triplets and thirty-second notes drawn as the nearest plain
     value; timewise scores refused; a short measure is padded to the signature unless
     the file marks it implicit; parts beyond the fifteenth are dropped. Not seen on a
     device yet: the tablature spacing and clef, and real files from MuseScore,
     TuxGuitar and Guitar Pro exports (only hand-written test scores so far).
   - A plain .xml is accepted by the library scan: one that is not a score is skipped
     silently on every scan (it is read again each time, cheap but not free).
